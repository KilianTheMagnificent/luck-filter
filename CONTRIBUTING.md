# Helping with luck-filter

Bug reports, unexpected numerical results, and reproducible test cases are welcome via GitHub Issues.

When opening an issue, please include:

- Your Python version (`python3 --version`)
- The exact command you ran
- A small, synthetic CSV or minimal input that reproduces the behavior (keep real trading records or private account data out of public issues)
- The expected output and the actual output you saw

Andre directs development with AI assistance and accepts feedback through issues only. Outside pull requests are turned off because Andre does not review outside code changes.

For a suspected security vulnerability, please use the private reporting instructions in [SECURITY.md](SECURITY.md).
