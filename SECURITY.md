# Security Policy

## Scope

`luck-filter` is a local-only, zero-dependency Python 3.9+ command-line tool and offline HTML companion (`skill-or-luck.html`). It does not handle logins, user accounts, passwords, encryption, backups, network requests, or trade execution.

## Reporting a Vulnerability

If you discover a security issue (for example, unsafe file/CSV handling or HTML/script injection in the companion page), please report it privately through GitHub's [Private Vulnerability Reporting](https://github.com/KilianTheMagnificent/luck-filter/security/advisories/new) instead of opening a public issue.

Please include reproduction steps and a minimal synthetic input so the issue can be confirmed safely.
